# Synthetic Data Dictionary

This dictionary describes the invented sample data included in this repository. It is a simplified, generalised version of the project structure and does not reproduce the confidential institutional dataset.

## Enrolment Sample

| Field | Description |
|---|---|
| `STUDENT_ID` | Invented identifier used to connect synthetic records |
| `ACADEMIC_YEAR` | Year in which the unit enrolment occurred |
| `UNIT_CODE` | Synthetic unit identifier |
| `UNIT_OWNING_FACULTY` | Faculty responsible for the unit |
| `UNIT_ATTENDANCE_MODE` | Internal, external or multi-modal attendance |
| `UNIT_STATUS` | Passed, failed, withdrawn or active |
| `GRADE` | Recorded unit result |
| `REPEAT_FAIL` | Whether the student repeatedly failed a unit |
| `ACADEMIC_YEAR_ATTENDANCE_TYPE` | Full-time or part-time study load |
| `COMBINED_COURSE` | Whether the student was enrolled in a combined course |
| `ADVANCED_STANDING_CREDIT_POINTS` | Credit awarded for recognised prior learning |
| `CREDITED_CREDIT_POINTS` | Credit awarded for equivalent prior study |
| `COMPLETED_CREDIT_POINTS` | Credit points completed within the course |
| `CURRENT_WEIGHTED_AVERAGE_MARK` | Current weighted average mark |
| `DOMESTIC_OR_INTERNATIONAL` | Domestic or international classification |
| `EQUITY_FLAG` | Synthetic indicator of whether equity criteria apply |
| `COURSE_ADMISSION_KEY` | Invented key for a student’s course admission |

## Retention Sample

| Field | Description |
|---|---|
| `STUDENT_ID` | Invented student identifier |
| `ACADEMIC_YEAR` | Base year used to assess the following-year outcome |
| `COURSE_CONTINUE_ENROLMENT_X1` | Whether the student continued in the same course |
| `FACULTY_CONTINUE_ENROLMENT_X1` | Whether the student continued in the same faculty |
| `UNIVERSITY_CONTINUE_ENROLMENT_X1` | Whether the student continued elsewhere in the university |
| `COURSE_COMPLETION_COUNT` | Whether a relevant course completion was recorded |
| `TRANSFER_COURSE` | Synthetic destination course for a transfer |
| `TRANSFER_FACULTY` | Synthetic destination faculty |
| `COURSE_ADMISSION_KEY` | Invented course-admission identifier |
| `CODE_TAG` | Progression category generated by the classification script |
